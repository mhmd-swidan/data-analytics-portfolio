# 🚀 Featured Projects

## 🛒 Retail Analytics

**SQL | Python | Power BI | DAX**

An end-to-end retail analytics project simulating an electronics retail business.

### Dataset

- 20,000+ Orders
- 5,000 Customers
- 200 Products

### Analysis

- Executive KPI Analysis
- Sales Performance
- Profitability Analysis
- Customer Analytics
- Cohort Analysis
- RFM-based Customer Segmentation

### Key Insights

- **$164.99M** total revenue
- **92%** customer repeat rate
- Champions + Loyal Customers represented **49% of customers but generated 72% of total revenue**
- Identified **$262.56K** in losses from negative-margin products
- Identified **12 customers** generating net losses

## 👥 Technova HR Analytics

**Python | Power BI | DAX**

An interactive HR analytics dashboard analyzing employee performance, compensation, and attrition.

### Dataset

- 1,000 Employees
- 10 Departments
- 5 Locations

### Key Insights

- **17%** overall attrition rate
- HR and Operations had the highest attrition at **22%**
- "Better Opportunity" and "Salary Issues" were the top exit reasons
- Average base salary ranged from **$5K at Entry Level to $30K at Manager**

### Tools

`Python` `Power BI` `DAX`
